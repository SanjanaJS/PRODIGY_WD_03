# Tic-Tac-Toe Web Application

## About the Project

This project is an interactive Tic-Tac-Toe web application developed as part of my Web Development Internship at Prodigy InfoTech.

The main purpose of this project is to create an engaging and user-friendly game using HTML, CSS, and JavaScript, allowing users to play Tic-Tac-Toe with another player or against an AI opponent.

## Purpose

The purpose of this project is to demonstrate basic web development and JavaScript programming skills, including:

- Creating a structured game interface using HTML
- Designing the game using CSS
- Adding interactive game functionality using JavaScript
- Handling user clicks and game events
- Tracking the game state
- Checking winning conditions
- Implementing an AI opponent
- Creating a responsive layout for different screen sizes

## How It Works

The application provides a 3 × 3 Tic-Tac-Toe game board where players can place their marks, X and O.

The game automatically switches turns between the players and checks the board after every move.

The application detects:

- Winning combinations
- Draw conditions
- Current player's turn
- Winning cells

Users can choose between two game modes:

- 2 Players
- Play vs AI

In AI mode, the user plays as X while the AI plays as O. The AI can identify winning opportunities and block the player's possible winning moves.

The application also maintains a scoreboard for:

- Player X
- Player O
- Draws

Users can restart the current round or reset the complete score.
